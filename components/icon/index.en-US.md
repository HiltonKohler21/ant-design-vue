Semantic vector graphics.

## How to use

Before using icons, you need to install the [@ant-design/icons-vue](https://github.com/vueComponent/ant-design-icons-vue) package:

```bash
# npm
npm install --save @ant-design/icons-vue

# yarn
yarn add @ant-design/icons-vue

# pnpm
pnpm add @ant-design/icons-vue

# bun
bun add @ant-design/icons-vue
```

## API

Since 2.0, `ant-design-vue` no longer includes the built-in Icon component. Please use the standalone `@ant-design/icons-vue` package.

### Common Icon

| Property | Description | Type | Default | Version |
| --- | --- | --- | --- | --- |
| class | The class name of Icon | string | - |  |
| rotate | Rotate by n degrees (not working in IE9) | number | - |  |
| spin | Rotate icon with animation | boolean | false |  |
| style | The style properties of icon, like `fontSize` and `color` | CSSProperties | - |  |
| twoToneColor | Only supports the two-tone icon. Specify the primary color, or primary and secondary colors | string \| \[string, string] | - |  |

We provide three different themes for icons, and the icon component name is the icon name suffixed by the theme name.

```html
<template>
  <StarOutlined />
  <StarFilled />
  <StarTwoTone two-tone-color="#eb2f96" />
</template>
<script lang="ts" setup>
  import { StarOutlined, StarFilled, StarTwoTone } from '@ant-design/icons-vue';
</script>
```

### Custom Icon

| Property | Description | Type | Default | Version |
| --- | --- | --- | --- | --- |
| component | The component used for the root node, typically a Vue component rendering an `<svg>` root element, or passed via the `#component` slot | Component \| slot | - |  |
| rotate | Rotate degrees (not working in IE9) | number | - |  |
| spin | Rotate icon with animation | boolean | false |  |
| style | The style properties of icon, like `fontSize` and `color` | CSSProperties | - |  |

### About SVG icons

We introduced SVG icons in version `1.2.0`, replacing font icons. This has the following benefits:

- Complete offline usage of icons, without dependency on a CDN-hosted font icon file (no more empty square during downloading and no need to deploy icon font files locally either!).
- Much better display accuracy on lower-resolution screens.
- Support for multi-color icons.
- No need to change built-in icons with overriding styles by providing more props in component.

More discussion of SVG icons can be found at [#10353](https://github.com/ant-design/ant-design/issues/10353).

All the icons will render to `<svg>`. You can set `style` and `class` for size and color of icons:

```html
<template>
  <MessageOutlined :style="{ fontSize: '16px', color: '#08c' }" />
</template>
<script lang="ts" setup>
  import { MessageOutlined } from '@ant-design/icons-vue';
</script>
```

### Set TwoTone Color

When using two-tone icons, you can use the static methods `getTwoToneColor()` and `setTwoToneColor(colorString)` to specify the primary color globally.

```ts
import { getTwoToneColor, setTwoToneColor } from '@ant-design/icons-vue';

setTwoToneColor('#eb2f96');
getTwoToneColor(); // #eb2f96
```

### Custom Font Icon

We added a `createFromIconfontCN` function to help developers use their own icons deployed at [iconfont.cn](https://iconfont.cn/) in a convenient way.

> This method is specified for [iconfont.cn](https://iconfont.cn/).

```html
<template>
  <MyIcon type="icon-example" />
</template>
<script lang="ts" setup>
  import { createFromIconfontCN } from '@ant-design/icons-vue';

  const MyIcon = createFromIconfontCN({
    scriptUrl: '//at.alicdn.com/t/font_8d5l8fzk5b87iudi.js', // generated by iconfont.cn
  });
</script>
```

It creates a component that uses SVG sprites (`<use>`) in essence.

The following options are available:

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| extraCommonProps | Define extra properties to the component | `{ [key: string]: any }` | `{}` |
| scriptUrl | The URL generated by [iconfont.cn](https://iconfont.cn/) project. Supports `string[]` | string \| string\[] | - |

The property `scriptUrl` should be set to import the SVG sprite symbols.

See [iconfont.cn documents](https://iconfont.cn/help/detail?spm=a313x.7781069.1998910419.15&helptype=code) to learn about how to generate `scriptUrl`.

### Custom SVG Icon

#### Vite

If you use `Vite`, you can configure [vite-svg-loader](https://www.npmjs.com/package/vite-svg-loader) to import `svg` files as Vue components:

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import svgLoader from 'vite-svg-loader';

export default defineConfig({
  plugins: [vue(), svgLoader()],
});
```

```html
<template>
  <Icon :component="MessageSvg" />
</template>
<script lang="ts" setup>
  import Icon from '@ant-design/icons-vue';
  import MessageSvg from './path/to/message.svg?component';
</script>
```

#### Vue CLI

You can import an SVG icon as a Vue component by using `Vue CLI` and [`vue-svg-loader`](https://www.npmjs.com/package/vue-svg-loader). See [`vue-svg-loader` docs](https://github.com/visualfanatic/vue-svg-loader) for options.

```js
// vue.config.js
module.exports = {
  chainWebpack: config => {
    const svgRule = config.module.rule('svg');

    svgRule.uses.clear();

    svgRule.use('vue-svg-loader').loader('vue-svg-loader');
  },
};
```

```html
<template>
  <Icon :component="MessageSvg" />
</template>
<script lang="ts" setup>
  import Icon from '@ant-design/icons-vue';
  import MessageSvg from 'path/to/message.svg'; // path to your '*.svg' file.
</script>
```

#### Rsbuild

Rsbuild is a next-generation build tool, official website https://rsbuild.dev/

Create a custom `vue-svg-loader.js` file and configure it in `rsbuild.config.ts`:

```js
// vue-svg-loader.js
/* eslint-disable */
const { optimize } = require('svgo');
const { version } = require('vue');
const semverMajor = require('semver/functions/major');

module.exports = async function (svg) {
  const callback = this.async();

  try {
    ({ data: svg } = await optimize(svg, {
      path: this.resourcePath,
      js2svg: {
        indent: 2,
        pretty: true,
      },
      plugins: [
        'convertStyleToAttrs',
        'removeDoctype',
        'removeXMLProcInst',
        'removeComments',
        'removeMetadata',
        'removeTitle',
        'removeDesc',
        'removeStyleElement',
        'removeXMLNS',
      ],
    }));
  } catch (error) {
    callback(error);
    return;
  }

  if (semverMajor(version) === 2) {
    svg = svg.replace('<svg', '<svg v-on="$listeners"');
  }

  callback(null, `<template>${svg}</template>`);
};
```

```ts
// rsbuild.config.ts
/* eslint-disable */
import { defineConfig } from '@rsbuild/core';
import { pluginVue } from '@rsbuild/plugin-vue';

export default defineConfig({
  plugins: [pluginVue()],
  tools: {
    bundlerChain(chain, { CHAIN_ID }) {
      chain.module.rule(CHAIN_ID.RULE.SVG).exclude.add(/\.svg$/);
    },
    rspack: {
      module: {
        rules: [
          {
            test: /\.svg$/,
            use: ['vue-loader', 'vue-svg-loader'],
          },
        ],
      },
      resolveLoader: {
        alias: {
          'vue-svg-loader': require('path').join(__dirname, './vue-svg-loader.js'),
        },
      },
    },
  },
});
```

The following properties are available for the `component`:

| Property | Description                                      | Type             | Default        |
| -------- | ------------------------------------------------ | ---------------- | -------------- |
| class    | The computed class name of the `svg` element     | string           | -              |
| fill     | Define the color used to paint the `svg` element | string           | `currentColor` |
| height   | The height of the `svg` element                  | string \| number | `1em`          |
| style    | The computed style of the `svg` element          | CSSProperties    | -              |
| width    | The width of the `svg` element                   | string \| number | `1em`          |

## FAQ

### Why does icon style sometimes cause global style error?

Related issue: [#54391](https://github.com/ant-design/ant-design/issues/54391)

When enabling CSS `layer`, dynamically injected icon styles may affect `@layer` priority and cause components to be styled abnormally.

This problem can be resolved by the two steps below:

1. Use the latest `@ant-design/icons-vue` alongside the current version of `ant-design-vue`.
2. Avoid static methods of `message`, `Modal`, and `notification`; prefer `useMessage`, `useModal`, `useNotification`, or the contextual instance provided by `<a-app>`.

If you must use static methods, you can render any icon component directly inside `<a-app>` to avoid style injection order issues caused by static methods:

```diff
 <a-style-provider layer>
   <a-config-provider>
     <a-app>
+      <!-- any icon -->
+      <RightOutlined />
       <!-- your pages -->
     </a-app>
   </a-config-provider>
 </a-style-provider>
```
