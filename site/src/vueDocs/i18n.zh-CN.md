# 国际化

`@hiltonkohler21/ant-design-vue` 目前的默认文案是英文，如果需要使用其他语言，可以参考下面的方案。

## ConfigProvider

`@hiltonkohler21/ant-design-vue` 提供了 [ConfigProvider](/components/config-provider-cn) 组件用于全局配置国际化文案。`ConfigProvider` 不包含时间类组件的日期格式化语言，需要额外导入并激活时间库（如 `dayjs`）的语言包。

```vue
<template>
  <a-config-provider :locale="locale">
    <a-space direction="vertical">
      <a-radio-group v-model:value="lang" @change="onLocaleChange">
        <a-radio-button value="zh-cn">简体中文</a-radio-button>
        <a-radio-button value="en">English</a-radio-button>
      </a-radio-group>
      <a-date-picker />
      <a-pagination :total="50" show-size-changer />
    </a-space>
  </a-config-provider>
</template>

<script setup lang="ts">
import { computed, ref } from 'vue';
import zhCN from '@hiltonkohler21/ant-design-vue/es/locale/zh_CN';
import enUS from '@hiltonkohler21/ant-design-vue/es/locale/en_US';
import dayjs from 'dayjs';
import 'dayjs/locale/zh-cn';

const lang = ref<'zh-cn' | 'en'>('zh-cn');
dayjs.locale('zh-cn');

const locale = computed(() => (lang.value === 'zh-cn' ? zhCN : enUS));

const onLocaleChange = () => {
  dayjs.locale(lang.value);
};
</script>
```

> 注意：`zh_CN` 是文件名，以下表格也遵循同样的规则。若日期组件语言未生效，请检查 `dayjs.locale(...)` 是否调用以及项目是否存在多个版本的 `dayjs`（运行 `npm ls dayjs` 排查）。
